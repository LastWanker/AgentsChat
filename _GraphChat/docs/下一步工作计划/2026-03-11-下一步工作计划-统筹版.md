## 3.2 P1.1b + P1.1c 检索与路由（已完成）

- `web_search/file_search/ask_peer` 已从占位升级为可替换 Provider。

## 3.3 P2 生产化接口（已完成首版闭环）

- 审批队列 API：`list pending -> resolve -> resume` 闭环。
- 流式接口：支持节点更新流与消息流输出。
- 观测快照：支持查看 checkpointer、agent 状态、审批状态与会话事件量。

## 3.4 P3 Agent 生命周期管理（已完成）

- 从静态 `agents=[...]` 升级为 `AgentRegistry` 驱动。
- 支持运行期 `upsert/enable/disable`，并与主群成员注册联动。
- 新增/禁用 agent 不改主图结构，仍沿用独立 `thread_id/checkpoint`。

## 4. 风险与约束（持续生效）

- 持续贴合 LangGraph/LangChain 官方 API；禁止节点内散落供应商 SDK 调用。
- 保持分层依赖：`interfaces -> application -> domain`，`application` 经端口访问 `infrastructure`。
- 所有可恢复流程保持 `compile(checkpointer=...)`。
