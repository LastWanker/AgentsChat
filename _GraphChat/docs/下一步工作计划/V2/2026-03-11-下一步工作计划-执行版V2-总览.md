## 0. 本版明确采纳的设计结论

1. `actions[]` 并行动作规划是主线，动作需包含 `target_scope/target_agents/priority/can_skip`。  
2. 并行动作编排在 `citation_guard` 之后，形成“一个入口、并行分发、汇聚回主干”的子图。  
3. 治理（投票/解散）是并行分支之一，默认可跳过（非治理动作不阻塞）。  
4. 相邻 guard 抽象成统一 `guardrail_subgraph`（policy/schema/action/idempotency）。  
5. `listening` 与 `silent_loop_subgraph` 形成内陷循环对：`listening -> silent -> listening`。  
6. 引入全图共享 TTL + 生命周期（working/idle/sleeping/lastlife），循环都消耗 TTL。  
7. WorldGraph 从“单轮结束”升级为“服务化常驻循环，手动结束优先”。  
8. 世界层提供产品编排能力：agent 生命周期、群关系、调度注入、直接对话、状态观测。  
9. V2 参数先固定：`ttl_initial=15`、`lastlife_threshold=3`、`speak_reply_window_seconds=10`（测试可切 `1`）。

## 1. 目标架构（高层）

## 1.1 AgentGraph（目标）

`listening_loop_subgraph -> decide_wake -> plan_action(actions[]) -> retrieval(optional) -> citation_guard -> action_parallel_subgraph -> guardrail_subgraph -> emit_events -> post_action_router`

- `post_action_router`：
  - `任务完成 -> listening_loop_subgraph`
  - `任务未完成且 TTL>0 -> decide_wake`（保持“醒着”）
  - `TTL耗尽 -> lifecycle_gate(lastlife/sleep)`  

## 1.2 WorldGraph（目标）

`ingest_world_commands -> ingest_external_events -> refresh_agent_registry -> route_scope -> schedule_agent_tasks -> run_agent(Send) -> collect_outputs -> broker_mentions_and_replies -> publish_stream -> world_loop_gate`

- 默认持续循环，不自动“业务终止”；仅 `stop_world` 命令或外部停止。

## 2. 官方用法对齐（强约束）

- LangGraph：
  - 图编排统一 `StateGraph/add_edge/add_conditional_edges/compile(checkpointer=...)`
  - 并行统一 `Send(...)`
  - 中断/审批统一 `interrupt(...) + Command(resume=...)`
  - 循环安全双保险：业务 TTL + `recursion_limit`
- DeepSeek：
  - 模型调用保持“无状态请求 + 受控窗口上下文”
  - LangChain 优先 `langchain-deepseek`，回退 `langchain-openai(base_url)`
  - 结构化输出统一 `with_structured_output(PydanticSchema)`

## 4. 对“世界强行放到某节点”的结论

该说法“语义可行、实现需收敛”：

- 不建议外部直接“跳转图内部 node_id”（强耦合、脆弱）。
- 建议世界注入“阶段意图（phase override）”到 AgentState，由路由节点解释并选择边。
- 若必须中断恢复式强制推进，优先 `interrupt/resume` 路径，而不是外部硬改图结构。
