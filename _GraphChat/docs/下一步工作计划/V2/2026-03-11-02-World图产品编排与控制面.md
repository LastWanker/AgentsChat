# 02 World 图产品编排与控制面（执行细案）

## 1. 改造目标

1. WorldGraph 从“单轮处理”升级为“服务化常驻循环，手动终止”。  
2. 世界成为老板接口与产品编排中枢。  
3. 支持 agent 状态观测、生命周期管理、群关系管理、任务注入、直接对话、调度注入。  
4. 明确 `@` 的两类语义：
   - 工作流语义（激活/上下文插入）
   - 直接交流语义（不改工作流主状态的一次性回应）

## 3. WorldGraph 节点重构

文件：`src/graphchat/application/graphs/world_graph.py`

目标节点流：

1. `ingest_world_commands`
2. `ingest_events`
3. `refresh_registry_and_scope`
4. `route_scope`
5. `schedule_agent_tasks`
6. `run_agent`（`Send(...)` 并发）
7. `collect_agent_outputs`
8. `broker_mentions_and_replies`
9. `commit_events`
10. `publish_updates`
11. `world_loop_gate`

`world_loop_gate` 规则：

- `world_running=False` 或收到 `stop_world` -> END
- 否则 -> 下一轮 `ingest_world_commands`

## 4. 世界控制面功能与实现点

## 4.1 agent 状态检查

来源：

- Runtime 内的 `get_observability_snapshot`（已有基础）
- Agent 执行回写状态：working/idle/sleeping/lastlife

落地点：

- `src/graphchat/application/runtime.py`
- `src/graphchat/interfaces/api/app.py`

## 4.2 新建 agent 与群关系维护

已有基础：

- `AgentRegistry`、`GroupRegistry`、`DmRegistry`

新增动作：

- 世界命令进入后在 `ingest_world_commands` 节点应用
- 成功后写系统事件（可审计）

## 4.3 对 agent 插话（normal/urgent）

规则：

- normal：只写入 agent 上下文待处理队列，不强制打断当前工作流
- urgent：注入 `phase_override="plan_actions"` 并附带紧急文本

实现点：

- `pending_injections` + `schedule_agent_tasks` 合并路由

## 4.4 世界与 agent 的直接交流（workflow 外）

目标：

- 提供一次性对话接口，不进入完整工作流链路
- 使用 agent 上下文 + 人设提示词生成即时回复

建议实现：

- Runtime 新增 `direct_chat_with_agent(...)`
- 结果事件类型建议 `direct_reply`
- 不写 `planned_actions`，不触发 board/governance/guard 主链

## 4.5 @ 机制（双向）

规则：

1. `@agent` 发生在 speak 事件里，先受 scope 可见性约束。  
2. 被 @ 的 agent 回复（若触发）应插入到发起者上下文中“靠近原 speak”的位置。  
3. speak 节点可有短等待窗口（`reply_wait_window_ms`）以便接收回贴回复。  
4. agent 也可 @ 其他 agent，但若目标不在 scope 内，视为无效 mention。  

实现点：

- `broker_mentions_and_replies` 节点负责 mention 捕获、目标校验、回复回贴。

## 5. “强行放到某个节点”问题的工程化表达

结论：保留需求语义，但替换表达与实现。

- 错误表达：外部直接指定内部 node id 跳转。
- 正确表达：世界注入 `force_phase` 命令，agent 路由节点解释该意图。
- 示例 phase：
  - `force_listening`
  - `force_plan`
  - `force_emit`

这能保持图内封装与低耦合，避免 API 与图拓扑硬绑定。

## 7. 测试清单

新增文件建议：

- `tests/integration/test_world_loop_service_mode.py`
- `tests/integration/test_world_command_create_agent_group.py`
- `tests/integration/test_world_injection_normal_urgent.py`
- `tests/integration/test_world_direct_chat_and_mention_broker.py`
- `tests/unit/test_scope_mention_constraints.py`

关键断言：

1. 世界默认持续循环，只有 `stop_world` 结束。  
2. normal/urgent 注入分流符合预期。  
3. scope 不可见时 @ 无效。  
4. direct_chat 不进入完整工作流但可读上下文。  
5. force_phase 通过路由生效，不依赖 node id。
