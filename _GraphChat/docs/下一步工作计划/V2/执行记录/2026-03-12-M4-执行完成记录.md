## 4. 对 World 图的结构理解（本轮结论）
- World 应该是“控制面编排器”，不是单纯事件中转器。
- World 主图保持稳定骨架，功能通过 handler/callback 扩展，才能做到“容易增删功能、低耦合”。
- `force_phase` 应表达为“阶段意图注入”，由 agent 路由解释，不暴露图内 node id。
- direct chat 与 workflow 并存：
  - workflow：完整 agent 图链路（含 board/governance/guard）
  - direct chat：一次性响应，不强制进入完整链路
