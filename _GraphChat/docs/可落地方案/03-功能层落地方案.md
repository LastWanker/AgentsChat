# 03 功能层落地方案

## 1. 记忆与检索层

## 1.1 分层存储

- 事实层：`events`（JSONL 或 SQLite）
- 执行层：LangGraph `checkpointer`
- 检索层：`tag_index + vector_index`
- 归纳层：`board_items + summaries`

规则：事实层唯一真源，检索层和归纳层均可重建。

## 1.2 RetrievalSubgraph 落地

入口：

- `citation_policy != none` 或动作类型要求证据

通道：

- `world_history`
- `ask_peer`
- `web_search`
- `file_search`

输出：

- `candidates[]`
- `retrieval_trace`
- `reroute_hint`（无结果时）

## 1.3 候选评分（规则优先）

```text
value_score =
  0.45 * semantic_sim +
  0.20 * source_weight +
  0.15 * freshness +
  0.10 * dependency_graph +
  0.10 * consensus
```

约束：

- 可计算特征由系统计算。
- LLM 仅做意图分类与理由生成，不直接拍脑袋给最终分。

## 2. 引用层

## 2.1 条件化引用

- `none`：允许无引用
- `optional`：可无引用；有引用则必须来自候选集
- `required_focus`：必须 1 个 `focus_reference`

## 2.2 引用结构

- `focus_reference`：0 或 1 个
- `support_references`：0..N 个
- `reference_role`：`focus|support|context|counter`

## 2.3 守卫节点

- `citation_guard_node`：按 `citation_policy` 执法
- 失败后返回结构化错误并触发改道（`ask_peer` / `web_search` / `defer`）

## 3. 协作与治理层

## 3.1 群结构

- 主群：`group:main`
- 小群：`group:<id>`
- 私聊：`dm:a:b`

## 3.2 治理动作（可扩展）

- `vote_decision`
- `dissolve_group`
- `assign_task`
- `maintain_board`

## 3.3 任务板（BoardSubgraph）

节点：

- `board_read_node`
- `board_update_node`
- `board_gc_node`

事件：

- `board_item_upserted`
- `board_item_deleted`
- `board_snapshot_generated`

## 4. HITL 与中断恢复层

标准流程：

1. `policy_gate` 命中审批规则
2. `interrupt(payload)` 暂停
3. UI 写入 Boss 决策事件
4. `Command(resume=...)` 恢复

幂等要求：

- 所有外部副作用前置 `idempotency_key` 检查
- `emit_event` 与 `tool_call` 分离为独立节点

## 5. 流式输入输出层

输出：

- 图级 `stream_mode="updates"`（节点状态）
- 模型消息流（token 流）

输入：

- `input_chunk`：草稿态更新，不触发全图
- `input_commit`：进入主流程

## 6. 节点实现模板（统一）

```python
from typing import TypedDict
from langgraph.types import Command

class AgentState(TypedDict, total=False):
    action: str
    citation_policy: str
    candidates: list
    focus_reference: str | None
    errors: list[str]

def citation_guard_node(state: AgentState) -> Command:
    policy = state.get("citation_policy", "none")
    focus = state.get("focus_reference")
    candidates = state.get("candidates", [])

    if policy == "required_focus" and (not focus):
        return Command(goto="retrieval_subgraph_entry", update={"errors": ["missing_focus_reference"]})
    if focus and focus not in {c["event_id"] for c in candidates}:
        return Command(goto="retrieval_subgraph_entry", update={"errors": ["focus_not_in_candidates"]})
    return Command(goto="policy_gate")
```

该模板固定了“状态输入/输出 + goto”，后续可把该节点平滑升级成子图。
