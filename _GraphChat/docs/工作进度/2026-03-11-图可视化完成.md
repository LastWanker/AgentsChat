# 工作进度（2026-03-11）- 图可视化完成

## 1. 本次目标

实现低耦合的状态机图可视化，支持：

- world/agent 图查看
- 悬停节点显示状态信息
- 点击含子图节点后，以暗色毛玻璃覆盖母图并显示子图

## 2. 已完成内容

## 2.1 可视化数据协议

- 新增通用图包协议导出器：`src/graphchat/interfaces/ui/graph_bundle.py`
- 产出 `graph_bundle.json`（图、节点元数据、子图关系）

## 2.2 元数据层

- 新增 `src/graphchat/application/graphs/graph_metadata.py`
- 统一维护节点说明、关键状态字段、源码位置、子图映射

## 2.3 导出脚本

- 新增 `scripts/export_graph_viewer.py`
- 自动导出：
  - `docs/graphs/graph_bundle.json`
  - `docs/graphs/graph_viewer.html`

## 2.4 前端查看器能力

- Mermaid 渲染主图与子图
- 节点悬停 tooltip（状态说明、关键字段、来源文件）
- 子图节点高亮
- 点击子图节点弹出毛玻璃 overlay

## 3. 使用方式

```powershell
python _GraphChat/scripts/export_graph_viewer.py
```

然后打开：

- `_GraphChat/docs/graphs/graph_viewer.html`

更稳方式（推荐）：

```powershell
python _GraphChat/scripts/serve_graph_viewer.py
```

访问 `http://127.0.0.1:8765/graph_viewer.html`。

## 4. 低耦合说明

- 查看器不依赖 GraphChat 运行时对象，只依赖 `graph_bundle.json` 协议。
- 其他项目只要输出同结构 JSON，即可复用当前前端查看器。

## 5. 下一步建议

- 将 Mermaid 资源改为本地静态文件，避免 CDN 依赖。
- 节点绑定从“文本匹配”升级为“显式 data-id”匹配，进一步增强稳定性。
